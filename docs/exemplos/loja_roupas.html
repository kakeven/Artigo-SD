Como funciona a compra

  1. 1. EscolhaPeça, tamanho e quantidade.
  2. 2. ReservaO serviço de estoque separa as unidades.
  3. 3. PagamentoUm serviço autoriza o valor fictício.
  4. 4. ConfirmaçãoO pedido é confirmado; se o pagamento falha, o sistema tenta liberar a reserva.
